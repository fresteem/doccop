# Code of Conduct

The doccop community follows version 2.1 of the **Contributor Covenant**.

The full text — including the standards we expect, examples of acceptable and unacceptable conduct, the enforcement process, and reporting guidelines — is available at:

**<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>**

That document is incorporated here by reference. By participating in this project (issues, pull requests, discussions, code review) you agree to abide by its terms.

## Reporting

Concerns about conduct in this project's spaces are handled privately. Report via **[GitHub Security Advisories](https://github.com/fresteem/doccop/security/advisories/new)** — the same private channel we use for security disclosures — and a maintainer will respond within three business days.

Do not file public GitHub issues for conduct concerns.

## Scope

This applies to all project spaces: the GitHub repository (issues, PRs, discussions, releases), the `@doccop/*` packages on npm, any official chat channel we run, and any conference or meetup talk given on behalf of the project.

## Enforcement

Maintainers may remove, edit, or reject contributions that don't align with this Code of Conduct, and will communicate reasons for moderation decisions where appropriate. Repeated or severe violations may result in a temporary or permanent ban from project spaces.
